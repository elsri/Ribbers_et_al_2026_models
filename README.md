# Ribbers_et_al_2026_models
Source code for the Canadian Fire Weather Index and US National Fire Danger Rating System (1977 version) used in Ribbers et al. 2026

The HCLIM3 climate data used as input in the two fire danger models can be found here:
https://archive.sigma2.no/dataset/EFAB0A80-AE6B-42BA-B020-66A308DE6E9A
Daily values can be derived from the subdaily input values by averaging for the wind speeds (derived from the U and V components), temperature and relative humidity variables, and by summing for the precipitation variable. Background data on elevation and land-use from HCLIM3 are not freely available.
